# M2: opt-in FEX execution

Branch: `t3/add-fex-execution-backend`. Work in progress; M2a is not complete.
Rosetta remains the default. No push, entitlement or system changes.

The first checkpoint extracts M1d initialization for reuse, then runs a real PE
entry through an arm64 FexProcess. Provider INT3 delivery is the next gate:
M1d qualifies SYSCALL and read AV, not Raven's breakpoint provider convention.
The existing NativeProcess is a concrete class, not a virtual backend interface;
its runtime selection and stopped-frame semantics need a thin Darwin seam.

Tests and reproduction commands will be recorded with the implementation.
