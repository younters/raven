# mtld3d for macOS

Raven's arm64 unix overlay uses [mtld3d](https://github.com/athei/mtld3d) v0.15.1 at
`9919759fa7c03362deac1b985db6d93de9e33ecf`, copyright Alexander Theissen, under the zlib license.
The build copies the license to the output. Cargo dependencies retain their own terms.

See [Raven's mtld3d patch](../../platform/darwin/mtld3d/patches/README.md) for the modifications and
[FEX graphics](../../platform/darwin/GRAPHICS.md#fex-graphics) for provisioning.
